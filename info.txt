[STEAM_TITLE:First Person View]
[STEAM_DESCRIPTION:Adventure mode in first person.

Press Ctrl-Shift-F (configurable) while playing an adventurer and the map turns into a first-person 3D view, drawn with the sprites the game already uses for the tiles, plants, items and creatures around you. Several z-levels are drawn at once, so you see hills, pits, multi-storey buildings and tree canopies. The rest of the adventure mode interface keeps working on top of the view, and pressing the hotkey again brings the normal map back.

Movement keys become relative to where you are looking: up walks forward, left and right turn.

It does not change raws or saves and does not need to be enabled for a world. The drawing is done by a native DFHack plugin (fpview) that has to be built for your DFHack version and placed in hack/plugins; see the README. Requires DFHack.]
